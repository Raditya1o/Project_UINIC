# Sibsku - Global Video Chat with AI Sign Language Translation

Website komunikasi video global dengan terjemahan bahasa isyarat real-time menggunakan AI.

## Cara Menggunakan

1. Buka `index.html` di browser untuk melihat landing page
2. Klik "Sign In" atau "Get Started" untuk ke halaman login (`login.html`)
3. Setelah login, Anda akan diarahkan ke dashboard (`dashboard.html`)
4. Dari dashboard, klik "START FACETIME" untuk memulai video chat (`videochat.html`)
5. Akses profil dan pengaturan melalui menu (`profile.html`)

## Struktur File

- `index.html` - Landing page / Homepage
- `login.html` - Halaman login/register
- `dashboard.html` - Dashboard utama setelah login
- `videochat.html` - Halaman video chat dengan AI translation
- `profile.html` - Halaman profil & pengaturan
- `landing.html` - Alternative landing page (editorial style)
- `styles.css` - Stylesheet utama dengan Aurora Design System
- `app.js` - JavaScript untuk routing, navigasi, dan fungsi interaktif

## Fitur Utama

✨ **AI Sign Language Translation** - Terjemahan bahasa isyarat real-time
🌍 **Global Random Chat** - Koneksi dengan pengguna dari 180+ negara
🔒 **Privacy by Design** - End-to-end encryption
♿ **Accessibility First** - Dirancang untuk pengguna dengan disabilitas
📱 **Responsive Design** - Bekerja di semua perangkat

## Teknologi

- HTML5, CSS3, JavaScript (Vanilla)
- Tailwind CSS (via CDN)
- Aurora Design System (custom color palette)
- WebRTC untuk video chat (simulasi)

## Browser Support

- Chrome/Edge (recommended)
- Firefox
- Safari
- Opera
